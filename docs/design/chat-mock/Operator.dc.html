What changed from v2
The mark is alive — it breathes when idle, the small disc orbits while Operator works, and it pulses when it is waiting on you.
Things arrive — every line springs in on its own beat, with the full sound language: rising when you send, a soft per-app note for each change it makes (reads stay silent), falling when it finishes, one low held note when it needs you, and distinct sounds for yes, no, unsure, and a message arriving.
Reads whisper, actions show — a read is one dim line. An action is a filled card that says what was done, in which app, and shows the result itself: the three stays with prices, the draft's first line.
The ask is a sheet — when something is irreversible, the conversation dims and a sheet rises with the question and one vermilion button. Nothing else is tappable until you answer.
No commands — the composer just says what it is for. The grid icon is the apps list, which is also where permissions live.
