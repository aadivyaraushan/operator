# Chat screen mock (main design)

The agreed design for the chat screen: header logo with its three motions,
plan steps, "Thought for" lines, the ask sheet, and the eight sounds.

Colors are the four from the brand doc only. Lettering is Montserrat
narrowed to 94%; the logo and icons keep their shape.

To view: serve this folder (`python3 -m http.server`) and open
`Operator.dc.html`. The iOS app does not match this yet.
